# AI-рієлтор для Telegram — MVP

Telegram-бот, який веде природний діалог з клієнтом українською, кваліфікує
лід (тип угоди, місто, район, тип об'єкта, кімнати, бюджет, телефон),
визначає «температуру» ліда (hot/warm/cold), шукає варіанти одночасно у
внутрішній базі та на RIELTOR.UA, і показує їх клієнту з кнопками реакцій
(«Зацікавило» / «Хочу перегляд» / «Не підійшло») прямо в чаті. Усі дані
одразу потрапляють у кабінет рієлтора (веб-CRM) з воронкою продажів та
історією реакцій на кожне оголошення.

## Архітектура

```
app/
  ai/            — діалоговий рушій на Claude (tool-calling) + fallback без API-ключа
  bot/           — Telegram-бот (aiogram): хендлери, клавіатури, форматування
  search/        — гібридний пошук: внутрішня база (SQL) + парсер RIELTOR.UA
  services/      — бізнес-логіка: кваліфікація лідів, реакції, воронка
  web/           — кабінет рієлтора (FastAPI + Jinja2): список звернень,
                   картка ліда, керування маршрутом, історія реакцій
  models.py      — SQLAlchemy-моделі (Lead, Property, Reaction)
  config.py      — налаштування через .env
```

## Швидкий старт

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # і заповніть TELEGRAM_BOT_TOKEN, ANTHROPIC_API_KEY

python -m app.seed_data     # наповнити внутрішню базу тестовими об'єктами
python -m app.seed_leads    # додати демо-ліди для кабінету рієлтора
python run_bot.py           # запустити Telegram-бота (long polling)
python run_web.py           # запустити кабінет рієлтора на http://localhost:8000
```

Кабінет рієлтора захищений HTTP Basic Auth (`WEB_ADMIN_USERNAME` /
`WEB_ADMIN_PASSWORD` в `.env`).

Якщо `ANTHROPIC_API_KEY` не задано, бот автоматично працює на легкому
rule-based fallback-двигуні (`app/ai/fallback.py`) — це дозволяє тестувати
весь потік (кваліфікація → пошук → реакції → CRM) без живого ключа.

## Тести

```bash
pytest
```

Покриті: евристичне вилучення полів з тексту, валідація/застосування
профілю ліда, авто-кваліфікація (hot/warm/cold), фільтрація внутрішнього
пошуку (в т.ч. постійне виключення оголошень з реакцією «Не підійшло»),
парсинг сторінки RIELTOR.UA на фікстурі HTML.

## Що вже працює (відповідно до MVP-специфікації)

- ✅ Telegram-бот з AI-діалогом українською (Claude tool-calling)
- ✅ Кнопкове меню вибору критеріїв (тип угоди, місто, район, тип об'єкта,
  кімнати, бюджет) — вільний текст лишається альтернативою, не обов'язковий
- ✅ Авто-кваліфікація: температура ліда (hot/warm/cold) + терміновість
- ✅ Гібридний пошук: внутрішня база + парсинг RIELTOR.UA (ліміт $100k)
- ✅ Інтерактивні кнопки реакцій на кожну картку об'єкта
- ✅ Кабінет рієлтора: картка ліда, воронка, наступна дія, останні звернення
- ✅ Журнал реакцій клієнта з постійним виключенням «Не підійшло»

## Поточні обмеження MVP (як і в оригінальній специфікації)

- Пошук тільки по Україні (Київ/Львів)
- Один рієлтор на систему (без мультитенантності/ролей)
- Текстові картки об'єктів без фото в чаті
- Ручне призначення переглядів (дата/час — рієлтор проставляє в кабінеті)
- Селектори парсера RIELTOR.UA — best-effort; якщо розмітка сайту зміниться
  або сайт недоступний, пошук деградує до внутрішньої бази без падіння бота

## Деплой на Railway

Щоб бот і кабінет рієлтора працювали постійно (не тільки поки увімкнений
ваш ПК) і кабінет мав публічне посилання для демонстрації — дивіться
покроковий гайд [`RAILWAY.md`](RAILWAY.md).
